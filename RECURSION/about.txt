1. What is a Recursion

so basically recursion means a fucntion that calls itself. 

def fun():
    print("Hello")
    fun()

here : 
fun()
 ↓
fun()
 ↓
fun()
 ↓
fun()
 ↓
...    

It will continue forever. So recursion needs a way to stop.
That stopping condition is called the:  Base Case

2. The Two Parts of Recursion
Almost every recursive problem has two important parts:

                 RECURSION
                    |
          ┌─────────┴─────────┐
          ↓                   ↓
     BASE CASE          RECURSIVE CASE
       Stop             Call itself

Base Case

Tells the function:

"Stop here."

Recursive Case

Tells the function:

"Solve a smaller version of the same problem."

FOR FACTORIAL 

n! = n × (n-1)!   --> That's our recursive relationship

Finding Base case:
0!  = 1 and 1! = 1

therefore :-

if n == 0 or n == 1:
    return 1


     Pseudocode
     factorial(n):

    IF n == 0:
        return 1

    return n × factorial(n - 1)

    dry run 
going down:-
5 × factorial(4)
5 × 4 × factorial(3)
5 × 4 × 3 × factorial(2)
5 × 4 × 3 × 2 × factorial(1)
5 × 4 × 3 × 2 × 1 × factorial(0)

base case:- 
factorial(0) = 1

Now return:
1
↓
1 × 1 = 1
↓
2 × 1 = 2
↓
3 × 2 = 6
↓
4 × 6 = 24
↓
5 × 24 = 120

output = 120 


POWER OF A NUMBER

x^n = x × x^(n-1)  --> That's our recursive relationship

Finding Base case:
n^0 == 1    any number to the power zero is 1

therefore:-
if n == 0:
    return 1

      Pseudocode
      power(x, n):

    IF n == 0:
        return 1

    return x × power(x, n-1)

Dry Run
power(2,5)

going down:
2 × power(2,4)
2 × 2 × power(2,3)
2 × 2 × 2 × power(2,2)
2 × 2 × 2 × 2 × power(2,1)
2 × 2 × 2 × 2 × 2 × power(2,0)

base case:
power(2,0) = 1

return:
1
2 × 1 = 2
2 × 2 = 4
2 × 4 = 8
2 × 8 = 16
2 × 16 = 32

COUNT DIGITS 

if n == 0 return 0   --> Base Case
n // 10 --> recursive Case 
it will reduce one digit from the end 
example:-- 12345 // 10 --> 1234 than 1234 // 10 --> 123 and so on 
      
       Pseudocode
       countDigits(n):

    IF n == 0:
        return 0

    return 1 + countDigits(n // 10)

    Dry Run
    countDigits(12345)

    Becomes: 
    1 + countDigits(1234)
    1 + 1 + countDigits(123)
    1 + 1 + 1 + countDigits(12)
    1 + 1 + 1 + 1 + countDigits(1)
    1 + 1 + 1 + 1 + 1 + countDigits(0)

    Base :- countDigits(0) = 0
    Answer :- 5

       SUM OF ARRAY 
       empty array → 0 --> Base Case

       Pseudocode :-

       sumArray(arr, index):
    IF index == length of array:
        return 0
    return arr[index] + sumArray(arr, index + 1)

     Dry Run:- 
     sumArray([2,4,6,8], 0)
     2 + sumArray(...,1)
     2 + 4 + sumArray(...,2)
     2 + 4 + 6 + sumArray(...,3)
     2 + 4 + 6 + 8 + sumArray(...,4)

     Reverse String


example:-  "hello"
Expected:"olleh"
One way to think:
hello
 ↓
reverse("ello") + "h"
Then:
reverse("ello")
 ↓
reverse("llo") + "e"
Eventually:
reverse("")
Base case:
return ""

Pseudocode:- 
reverse(string):
    IF string is empty:
        return ""
    return reverse(string[1:]) + string[0]

    Dry Run:- 
    reverse("hello")
reverse("ello") + "h"
reverse("llo") + "e" + "h"
reverse("lo") + "l" + "e" + "h"
reverse("o") + "l" + "l" + "e" + "h"
reverse("") + "o" + "l" + "l" + "e" + "h"

Base:
""

Result:
"olleh"
